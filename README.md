# toybox

[![schedule](https://github.com/dart-android/toybox/actions/workflows/schedule.yml/badge.svg)](https://github.com/dart-android/toybox/actions/workflows/schedule.yml)

```
docker run --rm -it --cap-add NET_ADMIN --cap-add NET_RAW ghcr.io/dart-android/toybox
```

## Supported tags

- `nightly`, `main`, `edge`
- `latest`, [Build ID](https://source.android.com/docs/setup/reference/build-numbers#build-ids-defined) from [Android CI](https://ci.android.com/)
- [Build ID](https://source.android.com/docs/setup/reference/build-numbers#build-ids-defined) from [Generic System Image releases](https://developer.android.com/topic/generic-system-image/releases)
